# Changelog

## 1.0.0 — 2026-11-06

container-map turns a local workspace into an interactive map of folders, files,
running agents and tasks. Counts come from the files and processes on your computer.

- Explore folders in a two-dimensional map or a three-dimensional view.
- Start coding tasks with installed agent tools, inspect changes and run checks before accepting them.
- See to-do notes, recent work and items waiting for your attention when you configure their sources.
- Ask the assistant about the map using Claude Code, Codex or Gemini installed on your computer.
- Try a generated demo workspace with a guided first visit.
- Pair a phone with an optional listener. Private folders show only names and counts on the phone.
- Scheduled jobs and running programs show their command lines with anything that could be a password,
  token or key hidden.
- Run with Python 3.10 or newer using the command line or an unpacked release zip.
